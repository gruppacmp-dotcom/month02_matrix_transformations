# Matrix transformations in Python with NumPy and Matplotlib

## Description
This tool visualizes how 2x2 matrices transform 2D space.

## Features
- Unit square transformation: Transforms the unit square into a parallelogram.
- Basis vectors: Draws basis vectors before and after transformation.
- Scaling/Rotation/Shear: Example matrix transformations.

## AI Connection
Neural network layers are matrices that transform input space. The columns of a matrix represent the new basis vectors.

## How to run
```bash
python main.py
```
